# Python Lab 1

## 1. Variable and Identifier Practice

### Aim
To declare variables for name, age, height, and student status and display their values with their data types.

### Logic
The program creates variables of different data types.
The `type()` function is used to display the data type of each variable.

### Sample Input / Output
No input is required.

Output:
Name: Devakshi Type: <class 'str'>
Age: 20 Type: <class 'int'>
Height: 5.4 Type: <class 'float'>
Student: True Type: <class 'bool'>


## 2. Greeting Program

### Aim
To take the user's name, age, and city and print a greeting sentence.

### Logic
The program takes name, age, and city using input().
An f-string is used to combine all three values into one sentence.

### Sample Input / Output
Input:
Name: Devakshi
Age: 20
City: Indore

Output:
My name is Devakshi, I am 20 years old, and I live in Indore.


## 3. Arithmetic Operations

### Aim
To perform basic arithmetic operations on two numbers.

### Logic
The program takes two numbers as input.
It calculates their sum, difference, product, quotient, and remainder.

### Sample Input / Output
Input:
First number: 10
Second number: 3

Output:
Sum: 13.0
Difference: 7.0
Product: 30.0
Quotient: 3.3333333333333335
Remainder: 1.0


## 4. Celsius to Fahrenheit

### Aim
To convert temperature from Celsius to Fahrenheit.

### Logic
The program takes Celsius temperature as input and converts it into a number.
The formula (C * 9 / 5) + 32 is used to calculate Fahrenheit.

### Sample Input / Output
Input:
Celsius: 25

Output:
Temperature in Fahrenheit: 77.0


## 5. String Manipulation

### Aim
To perform different operations on a full name.

### Logic
The program takes a full name as input.
It converts the name to uppercase, lowercase, reverses it, and calculates its length.

### Sample Input / Output
Input:
Devakshi Gour

Output:
Uppercase: DEVAKSHI GOUR
Lowercase: devakshi gour
Reversed: ruoG ihskaveD
Length: 13


## 6. Escape Sequence Practice

### Aim
To display a simple receipt using tab and newline escape sequences.

### Logic
The program uses \t to create spacing between item names and prices.
The receipt is displayed on separate lines to make the output neat.

### Sample Input / Output
No input is required.

Output:
Item        Price
--------------------
Pen         ₹20
Notebook    ₹50
Pencil      ₹10
--------------------
Total       ₹80
